Procedimento PREPARADO, NÃO EXECUTADO — depende de autorização posterior:
1. Conferir instância/banco e espaço livre; definir janela de manutenção.
2. Executar o script media-migration-backup.sql no SSMS e guardar o caminho/resultados.
   COPY_ONLY preserva a base de backups diferenciais; CHECKSUM e VERIFYONLY validam o backup.
   Conferir também acesso ao backup e, idealmente, restaurar numa instância isolada.
3. Confirmar WHATSAPP_MEDIA_ENABLED desabilitado e synchronize=false.
4. No PowerShell:
   Set-Location -LiteralPath 'C:\Projetos\whatsgestor\backend'
   npm.cmd run migration:show
   # Parar se houver qualquer pendente diferente de AddWhatsappMessageMedia1791600000000.
   # Somente após autorização explícita, backup verificado e ausência de novos pendentes:
   npm.cmd run migration:run -- --transaction all
   npm.cmd run migration:show
5. Conferir [X] na migration, tabela/índice/FK criados e ausência de outras alterações.
   O TypeORM acrescentará somente o registro de controle dessa migration em migrations.
6. Manter mídias desabilitadas. Ativação e teste real serão uma etapa posterior autorizada.
Não executar migration:revert automaticamente em caso de falha; revisar erro/transação primeiro.
Nenhum backup, RESTORE VERIFYONLY, migration:run ou migration:revert foi executado nesta revisão.
